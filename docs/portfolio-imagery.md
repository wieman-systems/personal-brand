# Portfolio imagery

Updated October 26, 2026. All 24 main project entries have images. The seven
historical AIGENTIC entries remain an archive index because their screenshots
have not been recovered.

## Source-based interface captures

Premier Fleet, Pixler HQ, V20 Fleet, Covenant, and Pioneer Timer were rendered
locally from their original application source. Only isolated capture copies
were adapted to supply fictional records and avoid live authentication, APIs,
or devices. No capture fixture, source checkout, authentication change, or
backend credential is included in the portfolio deployment.

- Premier Fleet: original shell, overview, KPI, chart, and status components;
  synthetic maintenance metrics and DEMO equipment identifiers.
- Pixler HQ: original command center and shell; fictional stays and properties.
- V20: original fleet cards and order manager; synthetic telemetry, sample clinics,
  and fictional order records.
- Covenant: original sample-deal workspace and projection view.
- Pioneer Timer: original race interface with nine fictional runners.
- Ghost Piston: original dashboard and engine selector in an isolated copy with
  audio and location requests disabled.
- Wieman OS and inbox actions: the repository's existing local demo server and
  synthetic dataset. The images carry an explicit synthetic-data label.
- Client delivery toolkit: original onboarding-guide template with an example
  client and account-specific fields removed.

The shipping entry explicitly distinguishes the pictured V20 order console from
the earlier WooCommerce-to-UPS workflow, which had no standalone dashboard.
The email entry explicitly identifies its screenshot as the related Wieman OS
inbox UI rather than a screenshot of the historical background watcher.

## Spatial imagery

Hunting and Crank use existing game-development captures. Total Chaos uses an
existing native-rendering test capture. Development uses a cropped simulator
launcher capture. WildWorld uses original creature and environment asset-pipeline
proofs, labeled as such rather than as headset screenshots. Existing GhostHands,
POLY, Stark, LibreQuake, Buckshot, A Restless Dream, and OU After Dark captures
retain their explanatory captions and upstream attribution.

Images are optimized JPEGs, except the existing transparent Crank menu PNG.
Interface thumbnails use `object-fit: contain` to preserve dashboard navigation
and controls. Every explainer image links to its original full-size local asset.
